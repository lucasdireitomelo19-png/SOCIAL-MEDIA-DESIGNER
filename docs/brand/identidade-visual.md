## Paleta de cores

| Uso sugerido        | Cor            | Hex       |
|----------------------|----------------|-----------|
| Fundo escuro (base)   | Azul-petróleo muito escuro | `#0B1E2E` |
| Fundo/bloco secundário| Azul petróleo  | `#1B4965` |
| Destaque frio         | Azul claro     | `#5FA8D3` |
| Texto claro / fundo alt| Off-white     | `#EDEDE9` |
| Destaque quente (CTA, chamadas) | Laranja/coral | `#F4A259` |

Uso recomendado: fundo em `#0B1E2E` ou `#1B4965`, texto principal em `#EDEDE9`, e `#F4A259` reservado para
palavras-chave, números e chamadas de ação (contraste quente sobre fundo frio). `#5FA8D3` para elementos
gráficos secundários (linhas, ícones, tags).

## Estilo visual — referências

Referências de mercado usadas como ponto de partida (recolorir sempre pra paleta da marca, nunca
usar as cores originais das referências):

- **Vitória Zuntini** — fundo sólido, headline bold condensado, lista com ícone de seta.
- **Carol Ferreira** — foto de fundo, headline estilo marcador/handwriting misturado com bold.
- **Josi Muniz** — foto de fundo, texto em caixa com borda pontilhada, mistura itálico + bold.
- **Jessi Lima** — fundo claro texturizado, headline serifado elegante com destaque de cor.
- **Mariana Guimarães** — foto de fundo, headline com palavra de destaque itálico.

Linha ativa: adaptar essas referências pra Anton (título) + Poppins (subtítulo/corpo), recolorido
pra paleta da marca. Primeira aplicação: layout da Vitória Zuntini (fundo sólido + lista com seta).
